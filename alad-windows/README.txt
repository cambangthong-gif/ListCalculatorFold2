ALAD Windows v1

- Windows 10/11 build 19041+.
- win-x64 and win-arm64 self-contained builds.
- Capture whole system excluding ALAD itself, or one selected process tree.
- Gemini 3.5 Live Translate fast mode (recommended).
- Experimental Gemini 3.8 Live custom-voice mode.
- Auto reconnect/session resumption/context compression.
- Auto Ducking / Voice-over / Parallel / Full dub.
- Manual sync, Auto Sync, Catch-up by dropping stale buffered translated audio, Low Latency.
- Input is sent as 16 kHz PCM in 100 ms chunks; output is 24 kHz PCM.

API key is entered at runtime and is not saved by this app.
