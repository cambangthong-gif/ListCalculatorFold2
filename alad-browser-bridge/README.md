# ALAD Browser Bridge v1.0

Tiện ích này dành cho **ALAD Windows v6 Hybrid Dubbing**.

## Cài trên Chrome / Edge

1. Giải nén thư mục này.
2. Chrome: mở `chrome://extensions` — Edge: mở `edge://extensions`.
3. Bật **Developer mode / Chế độ dành cho nhà phát triển**.
4. Chọn **Load unpacked / Tải tiện ích đã giải nén**.
5. Chọn đúng thư mục `alad-browser-bridge`.

## Dùng

1. Mở ALAD Windows v6.
2. Ở **Nguồn âm thanh**, chọn **Hybrid YouTube / Browser — phụ đề + sync trình phát**.
3. Bấm **Bắt đầu**.
4. Mở video YouTube. Tiện ích sẽ tự bật captions khi bridge đang hoạt động.
5. Pause / Play / Seek trên YouTube sẽ được gửi về ALAD.

Tiện ích chỉ kết nối tới `ws://127.0.0.1:37921/alad/` trên chính máy đang chạy ALAD.
